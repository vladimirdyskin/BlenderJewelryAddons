# Jewel Tools

Blender extension with tools for jewelry modeling workflows.

## Features

- Evenly space, spread, shuffle, and insert selected mesh faces.
- Rebuild the `Instance Face` Geometry Nodes setup.
- Add a non-destructive `Subdivide Local X` Geometry Nodes modifier before Curve.
- Link identical gem objects to shared mesh data while preserving their dimensions.
- Link repeated prong forms while preserving object transforms and Smooth by Angle.
- Capture high-resolution viewport snapshots.
- Access all tools from the `Jewelry` tab in the 3D View sidebar.

## Installation

Install the packaged ZIP using **Edit > Preferences > Extensions > Install from Disk**.
