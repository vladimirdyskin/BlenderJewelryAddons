# Pretty Ruler Overlay

Blender extension that draws styled dimensions over measurements created with the
native Measure tool.

## Features

- Distance and angle labels.
- Arrow, tick, or plain line end caps.
- Extension lines and leader labels for small dimensions.
- Configurable colors, text background, precision, and unit suffix.
- Per-measurement visibility controls.
- Optional hiding of the native ruler graphics.
- Linked dimensions: rulers glued to mesh faces update live while you edit the mesh.
  A ruler made with Shift (between faces) becomes a wall thickness.

## Usage

1. Create measurements with Blender's native Measure tool.
2. Open **3D View > Sidebar > View > Pretty Ruler**.
3. Enable the overlay. The measurement list updates automatically.
4. Click **Link to Geometry** to glue rulers that lie on mesh faces to those faces.

## Installation

Install the packaged ZIP using **Edit > Preferences > Extensions > Install from Disk**.
